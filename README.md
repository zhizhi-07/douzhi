# 豆织 (Douzhi) 🌊

> 液态玻璃iOS风格的AI社交应用 - 极简、干净、小巧精致

## ✨ 特点

- 🎨 **液态玻璃设计** - 毛玻璃效果，圆润小巧
- 📱 **iOS风格** - 极简交互，流畅动画
- 🔥 **性能优化** - 轻量级，快速响应
- 💎 **精致UI** - 所有元素都经过精心设计

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 🎯 设计理念

- **小巧精致**: 应用图标56x56，圆角16px
- **液态玻璃**: 半透明背景 + 高斯模糊 + 边框高光
- **流畅动画**: cubic-bezier缓动，0.3s过渡
- **触摸反馈**: 按下缩放92%，涟漪效果

## 🎨 颜色系统

- 玻璃背景：`rgba(255, 255, 255, 0.15)`
- 模糊强度：`blur(20px)`
- 边框高光：`rgba(255, 255, 255, 0.2)`
- 投影：`0 8px 32px rgba(0, 0, 0, 0.1)`
